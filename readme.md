# InfiMine

Minesweeper varianta v jediném HTML souboru – čistý vanilla JS, žádné závislosti, žádný build.
Hrací pole se generuje průběžně, takže hra nemá pevný konec: skóre roste s otevřenými políčky, nižší je lepší (méně min, méně značek, méně času).
Obsahuje časoměru s pauzou, žebříček skóre, auto-save/obnovu hry, tmavý režim a odhalení min po konci hry.
Celá hra je v souboru [`infimine.html`](infimine.html) – stačí otevřít v prohlížeči ([na GitHubu](https://github.com/strachonpavel/infimine/blob/main/infimine.html)).
